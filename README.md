# GVONavish C# 版

《大航海時代 Online》的航海地圖輔助工具。讀取遊戲畫面上的「測量」座標，在世界地圖上即時顯示船的位置、航向和船速，並能**自動避開陸地規劃航線**。

本專案是 [GVONavish](https://github.com/samedog/GVONavish)（C++）的 C# 重寫版，介面全中文。

下載：請到 [Releases](../../releases) 下載最新版本。

有問題、建議或使用心得：請到 [Discussions（討論區）](../../discussions) 發文；確定是程式錯誤的話請開 [Issue](../../issues)。

## 功能

### 即時航海
- **讀取座標**：在海上發動「測量」技能後，自動讀取遊戲畫面右下角的座標，不讀取、不修改遊戲記憶體。
- **擋掉讀錯的座標**：畫面被擋住或截到一半時可能讀出錯誤的數字；不合理的跳動會被擋下，連續兩次都在新位置才採用（例如重新登入）。
- **地圖跟隨船隻**：地圖以船為中心，可以拖曳、縮放（12.5%～400%），地圖左右相連可以繞地球。
- **航向線**：從船往前延伸的線。用直線擬合推算航向，約 5 秒穩定，對齊遊戲的 2 度精度。
- **船速**：以節（kt）顯示，可以放在畫面四個角落之一。
- **讀不到座標時變灰**：測量結束或進港後，船速和航向線變灰，表示是舊資料。
- **記住最後位置**：關閉程式時記住船的位置，下次在港口裡也能直接從這裡規劃航線。
- **深色模式**：右鍵 →「外觀」可以選淺色、深色或跟隨 Windows 設定（重新開啟程式後套用）。深色模式需要 Windows 11；Windows 10 一律是淺色。Windows 開啟高對比模式時，會照高對比的配色顯示。

### 航跡與航線管理
- 自動記錄走過的路線；超過 5 秒沒讀到座標就分成新的一段（讀取間隔設得很長時會自動放寬）。
- 航線管理視窗：加入我的最愛、與上一段連接、刪除、在地圖上顯示。
- 每段航線可以勾選要不要顯示在地圖上（右鍵選單有「全部顯示／全部隱藏」）。
- 航線可以取名字（F2 或「重新命名」）；規劃航線存成我的最愛時，自動取名為「起點 → 終點」。
- 航線自動存檔（`routes.json`），一般航線保留 30 段，我的最愛不限。

### 規劃航線（自動避開陸地）
- **16 方向 A\* 搜尋**，找出繞過陸地的最短海上航線，再拉直、收緊成幾段直線，並和海岸保持一點距離；窄海峽也過得去。
- **內建 206 個港口座標**，可以用中文、英文或區域名稱的任何一部分搜尋（例如「坦堡」「istan」「加勒比」），最近用過的港口排在最前面。
- **多段規劃**：一段接一段規劃，例如 里斯本 → 開普敦 → 卡利卡特。
- 顯示全程距離；讀得到船的位置時，再顯示**剩餘距離**和照目前船速大約還要多久（船沒有照著航線走也算得出來）。
- **考慮風向**：規劃航線時照每個海域的季節風向，找最省時間的路（以帆船、縱帆為準：順風到側風一樣快，過了側風慢慢變慢，正逆風剩 72%）。繞開逆風省下的時間比多走的路多時才會繞。
  - 右鍵選單的「風向」可以選夏季、冬季，或「不考慮風向」（走最短的路；槳帆船、蒸汽船受風的影響小，可以用這個）。
  - 逆風的航段（船速少一成以上）用橘色標出來；預計時間會把風向算進去。
  - 另一個季節走別條路明顯比較快（省 3% 以上）時，用紫色虛線一起畫出來；換季時兩條會對調。
  - 從「規劃航線」視窗規劃的航線，改風向時會照新的風向重新規劃；用滑鼠從船的位置規劃的不重算。
  - 地中海、黑海和伊比利半島外海不處理風向（地圖上沒有標，在裡面也沒辦法繞開）。
- 規劃航線可以存成「我的最愛」。
- 一般航線不到 0.5 秒，最遠的（例如里斯本到長崎）約 1～2 秒，計算時滑鼠顯示沙漏。

## 系統需求

- Windows 10 / 11
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（v0.9.6 以前的版本用 .NET 8）
- 《大航海時代 Online》，以視窗模式執行

## 編譯

需要 Visual Studio 2026（含「.NET 桌面開發」工作負載），或 .NET 10 SDK。

```bash
dotnet build -c Release
```

或用 Visual Studio 開啟 `GVONavishCS.slnx` 直接編譯。輸出資料夾會包含 `GVO.Common.dll`、`map.png`、`seamask.bin` 和 `winds.bin`，**這四個檔案要和 `GVONavish.exe` 放在同一個資料夾**。

### 專案結構

| 資料夾 | 內容 |
|---|---|
| `GVO.Common/` | 共用類別庫：找遊戲視窗、顯示縮放換算、截圖、安全存檔 |
| `GVONavish/` | 航海地圖程式（`GVONavish.exe`） |
| `GVODiscoverySync/` | 發現物同步：讀遊戲的發現物一覽，在安瑟兒的 Excel 打勾（`GVODiscoverySync.exe`，說明見該資料夾的 README） |

## 第一次使用

1. 開啟遊戲，出海後發動「測量」，讓畫面右下角出現座標。
2. 開啟 `GVONavish.exe`，地圖上應該會出現船的位置。
3. 如果讀不到座標：在地圖上按右鍵 →「讀座標設定…」，調整「距右下角 X／Y」，直到預覽框完整框住座標數字，黑白預覽裡的數字清楚可見。預設值是 70、273。

> **顯示縮放**：Windows 的顯示縮放不是 100%（例如筆電常見的 125%、150%）時，Windows 會把遊戲畫面整個放大，數字也跟著變大、變模糊。程式會自動偵測放大倍率並換算，截圖位置一樣用預設值 70、273（這兩個數字一律是遊戲原本的像素）。讀座標設定視窗會顯示目前的縮放比例。

> **遊戲多開**：同時開好幾個遊戲視窗時，程式先讀最前面的那個；讀到座標後就「鎖定」那個角色，之後一直讀它，即使把其他遊戲視窗切到前面也一樣。鎖定的角色約 3 秒讀不到座標（進港、測量結束、視窗被另一個遊戲視窗蓋住、關掉）後才解除，改讀最前面的視窗。換成另一個角色時，航跡會自動分段。狀態列會顯示目前是「鎖定這個角色」還是「讀最前面的視窗」。

## 操作方式

### 滑鼠

| 操作 | 效果 |
|---|---|
| 左鍵拖曳 | 移動地圖（會自動關掉「地圖跟隨船隻」） |
| 滾輪 | 放大縮小（沒跟隨船時，以滑鼠位置為中心） |
| 雙擊 | 在地圖上留下座標標籤；在標籤的十字上再雙擊一次就取消 |
| 雙擊船的圖示 | 回到船的位置並跟隨 |
| **Shift + 雙擊** | 從船目前的位置規劃航線到這裡 |
| **Ctrl + 雙擊** | 從上一段規劃航線的終點，接著規劃到這裡 |
| Ctrl + Shift + 雙擊 | 同上（GVONavi 的按法） |
| 右鍵 | 選單 |

規劃航線時（Shift／Ctrl＋雙擊、右鍵「規劃航線到這裡」），附近（60 個座標單位內）有港口會自動對準港口。雙擊留下的座標標籤不會移動，只在文字上註明附近的港口。

### 鍵盤

| 按鍵 | 效果 |
|---|---|
| 空白鍵 | 回到船的位置並跟隨 |
| Backspace | 刪掉最後一段規劃航線 |
| Esc | 清除座標標籤；沒有座標標籤時，清除規劃航線 |
| + / - | 放大縮小 |
| F1 | 視窗置頂 開／關 |

右鍵選單裡的「操作說明…」也列出了所有按法。

## 程式資料夾裡的檔案

| 檔案 | 說明 |
|---|---|
| `GVONavish.exe` | 程式本體 |
| `map.png` | 世界地圖（可以換成其他地圖，見下方說明） |
| `seamask.bin` | 海陸資料，規劃航線用。不見了會從附帶的 `map.png` 自動重建（約 2 秒） |
| `winds.bin` | 每個海域的季節風向，標出逆風的航段用。不見了程式照常可用，只是不標逆風 |
| `settings.json` | 設定（視窗位置、顯示選項、讀座標位置、最後位置等），自動產生 |
| `routes.json` | 航跡和我的最愛航線，自動產生 |
| `ports.json` | （選用）自訂港口，見下方說明 |
| `*.broken-日期時間` | 設定檔或航線檔讀不出來時，原檔會改成這個名稱保留，不會被覆蓋；需要時可以手動救回 |

存檔時先寫到暫存檔再換掉原檔，存到一半斷電或當機，原本的檔案也不會壞掉。

### 換地圖

右鍵 →「選擇地圖圖檔…」可以換成任何 2:1 的世界地圖（例如 4096×2048）。規劃航線一律用 `seamask.bin` 判斷海和陸地，和顯示哪張地圖無關，所以換地圖後規劃航線照常可用。

不同地圖的海岸線畫法可能有些微差異，航線在新地圖上偶爾看起來離岸很近，這是畫法不同，不影響使用。

### 自訂港口（ports.json）

內建港口沒有收錄內陸城市和商會開拓地。要新增或修正港口，在程式資料夾放一個 `ports.json`：

```json
[
  { "Name": "新阿姆斯特丹", "Region": "開拓地", "X": 1234, "Y": 1234, "English": "New Amsterdam" }
]
```

- `Region`、`English` 可以省略。英文名有好幾種寫法時用 `|` 分開，例如 `"Porto|Oporto"`。
- 和內建港口同名時，以這個檔案為準，可以用來修正座標。

## 運作原理

| 項目 | 做法 | 程式碼 |
|---|---|---|
| 讀座標 | 截下遊戲畫面右下角 60×11 像素，轉成黑白，逐欄比對 0～9 的點陣樣本 | `Core/SurveyCoordExtractor.cs`、`Core/GameWindowCapture.cs` |
| 擋掉讀錯的座標 | 和上一個位置比較，超過船可能的移動距離就先不採用，連續兩次在新位置才接受 | `Core/CoordFilter.cs` |
| 航向 | 同一段直線航行的所有讀數做最小平方法直線擬合；只看「左右偏離」判斷轉彎，對齊 2 度 | `Core/ShipMotion.cs` |
| 船速 | 約 5 秒前的位置到現在位置的直線距離 ÷ 經過時間，避免整數座標鋸齒造成高估 | `Core/SpeedMeter.cs` |
| 海陸判斷 | 從附帶地圖的固定顏色分出海和陸地，存成 `seamask.bin`（1 位元／格，GZip 壓縮） | `Core/SeaMap.cs` |
| 規劃航線 | 16 方向 A\*（靠近海岸的格子成本較高）→ 從最遠處往回拉直 → 像橡皮筋一樣收緊 | `Core/RoutePlanner.cs` |
| 規劃航線的剩餘距離 | 找出航線上離船最近的點：船到那個點的距離 ＋ 從那個點沿航線到終點的距離；來回的航線用上一次的進度分辨去程和回程 | `Core/RouteProgress.cs` |
| 季節風向 | 每個海域夏季、冬季的風向（從中文地圖的箭頭整理成 `winds.bin`）；縱帆從順風到側風船速不變，過了側風慢慢變慢，正逆風剩 72%；船速少一成以上的航段標成逆風 | `Core/WindMap.cs`、`Core/Sail.cs`、`Core/RouteWind.cs` |
| 港口資料 | 內建 206 個港口的座標、中英文名稱；支援模糊搜尋 | `Core/Ports.cs` |

遊戲世界座標為 16384 × 8192，左右相連。

## 已知限制

- 遊戲視窗必須在螢幕上看得到，座標區域不能被其他視窗擋住（截圖方式和原版相同）。
- 座標是整數，航向需要約 5 秒才能精確到 2 度，這是整數座標本身的限制。
- 內建港口不含內陸城市和商會開拓地；可以用 `ports.json` 自行補充。
- 航線規劃以地圖上的海陸和季節風向為準，不考慮海流、海域危險度。很長的航線（例如繞半個地球）考慮風向時要算好幾秒。
- 風向的影響是估計：風向用的是每個海域的季節風向（遊戲裡會在這個方向附近變動），船速和角度的關係只在一個海域（馬德拉海域、冬季）用帆船實測過，誤差在 3% 以內；其他海域的風力不一定一樣強。

## 與原版的差異

| | GVONavish（C++） | 本專案（C#） |
|---|---|---|
| 介面語言 | 日文／英文 | 繁體中文 |
| 繪圖 | OpenGL | GDI+ |
| 航向穩定時間 | 約 9 秒（中位數） | 約 4 秒（中位數） |
| 船速 | 每一步速度平均，斜向航行高估約 7% | 位移法，誤差約 2% |
| 讀錯座標 | 直接採用 | 過濾 |
| 存檔 | 只存我的最愛（二進位） | 全部航線（JSON） |
| 規劃航線 | 無 | 自動避開陸地、多段、港口搜尋 |
