> ⚠️ **測試版（Pre-release）**：功能還在持續改進中，可能遇到讀不準或判斷錯誤的情況。
> 寫入前程式會自動備份 Excel（在 `backup\` 資料夾），遇到問題歡迎到 [Issues](https://github.com/chucheemeng-creator/GVONavishCS/issues) 回報，附上「存下遊戲畫面」存的檔案會更好處理。

讀取《大航海時代 Online》「發現物一覽」的畫面，自動在安瑟兒的發現物統計 Excel 幫角色打勾，不用再一個一個找、一個一個填。

> 只看遊戲畫面，**不讀取、不修改遊戲記憶體，也不會對遊戲按任何按鍵或滑鼠**；捲動清單由你自己操作。

## 這一版的改進（和 v0.2.51 比）

- **港口類的「關島」讀得到了**：Excel 的地理類也有「關島」，所以港口類那一個寫成「關島(港)」，遊戲上卻只顯示「關島」，以前一直「找不到」。現在地理、港口的關島都能正確辨識，寫入時各自寫到自己那一列。
- **名稱對照表**：像這種 Excel 和遊戲寫法不同的名稱，放在程式旁邊的 `GVODiscoverySync.NameAliases.json`（第一次執行時自動建立），左邊是 Excel 的寫法、右邊是遊戲上的寫法。
  以後 Excel 改版又遇到新的，自己加一行就好，不用等新版程式；程式開著也可以改，存檔後下一次讀取畫面就套用。
- 每次修改都會在 GitHub 上自動編譯、跑過全部的測試；這一版的檔案也是 GitHub 自動建置的。

## 下載

解壓縮後只有一個 `GVODiscoverySync.exe`，放在自己的資料夾即可執行（例如 `D:\Tools\` 或「文件」底下）。
**請不要放在 `C:\Program Files`**，那裡不能寫入，設定會存不起來。
從舊版更新：直接用新的 exe 蓋掉舊的即可，設定、錯字對照表、名稱對照表都會保留。

## 使用前請先確認

1. **安裝 .NET 10 Desktop Runtime**
   本程式不含 .NET 執行環境，未安裝會打不開。
   下載：https://dotnet.microsoft.com/download/dotnet/10.0 → 「.NET Desktop Runtime」→ Windows x64
2. **Windows 要有繁體中文的文字辨識**
   「設定 → 時間與語言 → 語言與地區」新增「中文（繁體，台灣）」。
   沒安裝的話，程式啟動時會提示。
3. **安瑟兒的發現物統計表（.xlsx）**

系統需求：Windows 10（2004 以後）/11，遊戲以視窗模式執行。
實測可用的環境：800×600、1280×720，Windows 顯示縮放 100% 與 150%。

## 用法

1. 按「選擇…」選 Excel 檔案，選要打勾的人物。
2. 遊戲裡打開「發現物」→ 選分類 →「一覽顯示」。
3. 按「開始讀取」，在遊戲裡把清單從頭捲到尾，每次停下來就會讀一頁。
4. 換下一個分類，一樣捲一遍。
5. 檢查清單：「找不到」「不確定」「推斷」「讀不出來」的列，按右鍵 →「指定 Excel 發現物…」確認或手動選。
6. **關閉 Excel**，按「寫入 Excel」。

詳細說明請看 [GVODiscoverySync 的 README](https://github.com/chucheemeng-creator/GVONavishCS/tree/master/GVODiscoverySync)。

## 小提醒

- 本程式的視窗不要擋住遊戲的清單。按 **F1** 可以切換視窗置頂。
- 寫入前會自動把原檔備份到 Excel 所在資料夾的 `backup\`，寫錯了可以還原。
- 讀不準時按「存下遊戲畫面」，把 exe 旁邊 `screens\` 資料夾裡的檔案附在 Issue 裡回報。
