# 發現物同步（GVODiscoverySync）

讀《大航海時代 Online》的「發現物一覽」畫面，自動在安瑟兒的發現物統計 Excel 幫角色打勾。

只看遊戲畫面（和 GVONavish 讀座標一樣），**不讀取、不修改遊戲記憶體，也不會對遊戲按任何按鍵或滑鼠**。

## 系統需求

- Windows 10（2004 以後）/ 11
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)
- **繁體中文的文字辨識**：Windows「設定 → 時間與語言 → 語言與地區」新增「中文（繁體，台灣）」，語言選項裡要有「光學字元辨識」。程式啟動時會檢查，沒有的話會提示。
- 安瑟兒的發現物統計表（.xlsx）

## 用法

1. 按「選擇…」選 Excel 檔案，選要打勾的人物（名稱取自 Excel 首頁第 2 列）。
2. 遊戲裡打開「發現物」→ 選一個分類 →「一覽顯示」。
3. 按「開始讀取」，在遊戲裡把清單從頭捲到尾（按 ▼ 或滾輪都可以）。每次畫面停下來就讀一次，讀過的不會重複。
4. 換下一個分類，一樣捲一遍。
5. 檢查清單：
   - **新增**：會寫入（可以取消勾選）
   - **已經打勾**：Excel 裡本來就有勾
   - **不確定**：有兩個很像的名稱，預設不寫入，確認後自己勾選
   - **找不到**：Excel 裡沒有對應的名稱（辨識錯字、或是新版本的發現物），請手動處理
6. **關閉 Excel**，按「寫入 Excel」。寫入前會在同一個資料夾備份原檔（`檔名.bak-日期時間.xlsx`）。

> 本程式的視窗不要擋住遊戲的清單，否則會截到自己的視窗。

## 讀不準的時候

按「存下遊戲畫面」，截圖會存在程式資料夾的 `screens\`（檔名帶縮放倍率，例如 `-s1.5`）。
之後可以用「用截圖檔測試…」重讀，也方便回報問題。

清單位置存在 `GVODiscoverySync.json` 的 `Layout`（遊戲原本的像素，相對於遊戲畫面正中央），目前只在 800 × 600 量過。
