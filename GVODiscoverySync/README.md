# 發現物同步（GVODiscoverySync）

讀《大航海時代 Online》的「發現物一覽」畫面，自動在安瑟兒的發現物統計 Excel 幫角色打勾。

只看遊戲畫面（和 GVONavish 讀座標一樣），**不讀取、不修改遊戲記憶體，也不會對遊戲按任何按鍵或滑鼠**。

## 系統需求

- Windows 10（2004 以後）/ 11
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)
- **繁體中文的文字辨識**：Windows「設定 → 時間與語言 → 語言與地區」新增「中文（繁體，台灣）」，語言選項裡要有「光學字元辨識」。程式啟動時會檢查，沒有的話會提示。
- 安瑟兒的發現物統計表（.xlsx）

## 用法

1. 按「選擇…」選 Excel 檔案，選要打勾的人物（名稱取自 Excel 首頁第 2 列）。
2. 遊戲裡打開「發現物」→ 選一個分類 →「一覽顯示」。
3. 按「開始讀取」，在遊戲裡把清單從頭捲到尾（按 ▼ 或滾輪都可以）。每次畫面停下來就讀一次，讀過的不會重複。
4. 換下一個分類，一樣捲一遍。
5. 檢查清單：
   - **新增**：會寫入（可以取消勾選）
   - **推斷，請確認**：整列讀不出來、由前後列推斷出來的（相似度欄顯示「推斷」），預設不寫入，確認後自己勾選
   - **已經打勾**：Excel 裡本來就有勾
   - **不確定**：有兩個很像的名稱，預設不寫入，確認後自己勾選
   - **同名，請確認**：遊戲上同名、Excel 用數字區分的（例如「聖母加冠1」「聖母加冠2」），分不出是哪一個（只有同一頁同時看到全部、或依價值排列時用功績判斷出來的，才算確定）
   - **找不到**：Excel 裡沒有對應的名稱（辨識錯字、或是新版本的發現物），請手動處理
   - **讀不出來，請手動確認**：這一列有字但怎麼讀都讀不出來，Excel 名稱欄會寫它在哪兩個發現物之間
   - **手動修正**：在任何一列按右鍵 →「指定 Excel 發現物…」（或選取後按 Enter），從清單挑正確的發現物；
     依和畫面文字的相似度排序，可以打字搜尋，分類判斷錯了也能換；列出 ★、任務／地圖幫忙判斷。選好後是「新增（手動指定）」。
     辨識出來的垃圾列按右鍵 →「移除這一筆」（或按 Delete）。手動處理過的列，繼續捲動時再讀到也不會加回來。
6. **關閉 Excel**，按「寫入 Excel」。寫入前會把原檔備份到 Excel 所在資料夾的 `backup\`（`檔名.bak-日期時間.xlsx`）。

> 本程式的視窗不要擋住遊戲的清單，否則會截到自己的視窗。
> 按 **F1** 切換視窗置頂（遊戲在前面時也看得到本程式），會記住下次開啟時的狀態。

## 怎麼辨識的

- **影像處理**：清單每一列各自找出底色，轉成白底黑字、放大 3 倍再交給 Windows 的文字辨識；每一頁用 2.5、3、3.5 倍各讀一次，每一列挑最像 Excel 名稱的結果。
- **分類**：先讀左上角的分類標題；標題只有兩、三個字，常常讀不出來，這時從清單上的名稱推測是哪個分類。
- **比對**：名稱用模糊比對，對漏字特別寬容（辨識最常見的錯是漏掉筆畫密的字）。
- **同一頁推斷**：同一頁每一列都是不同的發現物；清單照名稱的字元編碼排序時（預設的排序），每一列一定排在上下兩列之間。用這兩點排除不可能的候選。
- **排序方式**：每一頁判斷是「依價值」（功績由高到低）還是「依名稱」（字元編碼由小到大）排列。證據充分的頁面（至少 4 個已確定的列、只符合其中一種）會記住排序方式，發現物少、證據不足的頁面沿用它；兩種都符合時不下判斷，免得誤判。用只有 1%～3% 發現物的新手資料模擬過，沒有判斷錯的情況。
- **同名的發現物**：遊戲上同名、Excel 用數字區分（例如「水鹿」「水鹿2」）。依價值排列時用上下鄰居的功績判斷是哪一個（同名的各個功績都不同）；另外記住每一個的上下鄰居，鄰居不同就是不同的一個，所以分散在不同頁也數得出來。

## 錯字對照表

文字辨識固定會讀錯的字（例如「鑽」每次都讀成「巑」、「海」拆成「冫每」），放在 `GVODiscoverySync.json` 的 `OcrConfusions`，左邊是讀到的、右邊是正確的。比對時照原樣、換字後各比一次，取比較像的，所以原本就有這個字的名稱不受影響。

內建的錯字每次啟動都會自動補進設定檔，自己加的不會被蓋掉。不想用某一組內建的，把它改成對應到自己（例如 `"專": "專"`）。

## 讀不準的時候

按「存下遊戲畫面」，程式資料夾的 `screens\` 會存下四個檔案（檔名帶縮放倍率，例如 `-s1.5`）：
- `….png`：遊戲畫面原圖，之後可以用「用截圖檔測試…」重讀
- `…-title.png`、`…-list.png`：辨識前處理好的分類標題和清單
- `….txt`：每一列讀到的原文，和比對到的 Excel 名稱

設定檔 `GVODiscoverySync.json` 也在程式資料夾（從 Visual Studio 執行時是 `bin\Debug\net10.0-windows10.0.19041.0\`）。

清單位置存在 `GVODiscoverySync.json` 的 `Layout`（遊戲原本的像素，相對於遊戲畫面正中央）。實測可用的環境：800 × 600 ＋ 顯示縮放 100%、800 × 600 ＋ 150%、1280 × 720 ＋ 100%。
